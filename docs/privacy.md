# 揪鏡 v0.3 隱私政策

更新日期：2026-09-30。適用版本：0.3.x 開發版（隨該版本發佈生效）。維護者：JiuJing Lab 揪鏡實驗室。

揪鏡協助使用者在自己有權檢查的空間及網路觀察裝置線索。v0.3 沒有帳號、廣告、分析 SDK、遠端規則更新或雲端偵測。

## 權限與處理資料

| 權限 | 用途 | 暫時處理的資料 |
|---|---|---|
| 本機網路 | 一般掃描探索同一 Wi-Fi 的常見 TCP 端口與 Bonjour；另行啟動「拍攝來源驗證」並確認存取授權後，讀取指定裝置的 RTSP 描述或 JPEG／MJPEG 畫面；不登入設備 | IPv4 位址、端口、服務資訊；驗證時另有指定網址、SDP 描述及短暫影像 buffer，僅記憶體處理，不快取、不存檔、不上傳 |
| 藍牙 | 讀取周圍 BLE 廣播；不配對、不連線 | 裝置名稱、系統產生的識別碼、服務 UUID、RSSI |
| 相機（選用） | 使用者啟動相機後，提供預覽、放大、補光；可選紅外線亮點或即時視覺模式 | 預覽模式不安裝擷取輸出；分析模式以 AVCaptureVideoDataOutput 逐幀處理亮度及輪廓，每秒最多分析兩幀，不拍照、不錄影、不儲存、不上傳 |
| 使用 App 期間的精確位置（選用） | iOS 要求此授權才能讀取目前連線的 Wi-Fi | SSID 與存取點 BSSID；不呼叫位置更新、不取得 GPS 座標、不做背景定位。不使用此功能可手動輸入 SSID |
| 麥克風（選用） | 使用者啟動後，分析 10 秒環境音頻譜與窄帶音 | 原始聲音僅在短暫記憶體 buffer 中處理，分析後釋放；不錄製檔案、不辨識語音、不上傳 |
| 手動輸入（無額外權限） | 比對 MAC 廠商前綴、SSID 名稱及選填的 RSSI | 輸入與比對結果只存於頁面記憶體，不主動讀取剪貼簿 |

不要求聯絡人或相簿權限。相機、位置與麥克風均在使用者啟動對應功能時才要求授權，拒絕不影響其他功能。BLE 識別碼不是 MAC 位址。存取點 BSSID 不是周邊攝影機的 MAC。

## 保存與刪除

結果只在目前 App 程序記憶體中保存，不建立磁碟掃描紀錄，也不傳送給維護團隊或第三方。按「清除」、重新開始對應掃描或 App 程序結束後，對應結果即刪除。MAC／Wi-Fi 輸入及結果可用該頁「清除輸入與結果」刪除。相機與麥克風在停止、關閉頁面或 App 進入背景時關閉，返回前景不會自行啟動；音訊正常完成 10 秒也會停止。App 進入背景停止掃描與 Wi-Fi 讀取；背景中的記憶體結果不等於已經清除。

使用者自行截圖、錄影或向他人分享畫面時，可能揭露周邊裝置資訊，請自行確認畫面內容。App 不提供自動分享或上傳。

拍攝來源驗證只向目前 Wi-Fi 同子網的私有 IPv4 裝置送出單次 HTTP GET 或 RTSP DESCRIBE，不跟隨重新導向、不枚舉路徑、不送帳密；裝置本身可能記錄這次存取。最多接收 20 MiB，HTTP 最多 30 秒、RTSP 最多 10 秒。停止後可保留最後畫面及確認狀態於記憶體，畫面明確標示非持續直播；離開頁面或進背景即停止並清除影像。「清除畫面與結果」會一併刪除該頁的確認狀態。現場畫面確認是使用者的手動回報，不是系統對偷拍的自動判定。

## 外部連結與聯絡

原始碼及問題回報連結會以外部瀏覽器開啟 GitHub，其網站行為適用 GitHub 的隱私政策。請勿在公開 Issue 貼上私人空間、裝置識別碼、影像或聯絡資料。

公開問題回報：https://github.com/JiuJingLab/ios/issues 。未來若加入雲端處理或帳號功能，會另行更新政策並於功能使用前說明。
