| 時間 | 實機畫面與操作 | 可直接照念的旁白 |
|---|---|---|
| 00:00–00:15 | iPhone 開啟揪鏡，停留首頁；不要先放長片頭 | 入住陌生空間時，很多人擔心隱私，卻不知道從哪裡檢查。揪鏡是一款免費、開源的 iPhone 工具，幫你把周遭裝置轉成可以人工確認的線索。 |
| 00:15–00:30 | 顯示 Wi-Fi 區網模式，勾選有權檢查，點開始；首次權限提示如實錄下 | 我們只在自己有權檢查的空間與網路使用。連上測試 Wi-Fi，確認授權後開始。揪鏡檢查同網路的常見端口與廣播服務，不讀取攝影機影像。 |

## 錄製準備

- 真實 iPhone／iPad、已安裝並驗證的 build、受控 Wi-Fi、自己管理的測試 HTTP／RTSP 服務、BLE 測試廣播器。
- 事先將測試裝置名稱設成無個資名稱，使用獨立測試網段；開啟勿擾，避免通知與個人資料入鏡。不要錄到 API Key、Token、Apple 帳號、其他住戶的裝置。
- 先計時排練。區網約 30–40 秒時可落在上述時間配置；若超時，可壓縮旁白與其他段落，不超過 3 分鐘。不要加速或剪接成不實的偵測速度。
- 影片可加旁白，但核心必須是真實操作錄影；不得用模擬器或合成結果冒充實機功能驗證。
- 上傳 YouTube，可設「不公開」，允許嵌入；用登出狀態確認可播放。標題建議：`揪鏡 JiuJing｜免費開源的隱私自我檢查工具｜v0.1 實機展示`。
